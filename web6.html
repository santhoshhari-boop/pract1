Staticposition: static

The default. Elements follow normal document flow; top/left/z-index have no effect.

Order intake panel
Warehouse allocation panel
Dispatch panel
.panel { position: static; /* default */ }

Industry use: all regular content, such as articles, forms and dashboards, where layout is handled by flex/grid.

Relativeposition: relative

Offset from its normal spot while still reserving its original space. Its main job is to become the anchor for absolute children.

Industry use: positioning contexts for badges and tooltips, and small hover or micro-interaction shifts.

Fixedposition: fixed

Positioned relative to the viewport and stays put while scrolling. This page uses it twice: the top navbar and the support button at the bottom right.

.nav  { position: fixed; top: 0; left: 0; right: 0; }
.chat { position: fixed; right: 20px; bottom: 20px; }

Industry use: global headers, cookie banners, chat widgets and floating action buttons. Reserve space (padding-top) so content isn’t hidden underneath.

Stickyposition: sticky

Acts like relative until a scroll threshold is reached, then sticks. Scroll the table below; the header stays visible. The contents sidebar on the left is sticky too.

OrderRouteStatus
thead th { position: sticky; top: 0; background: var(--surface); }
.toc     { position: sticky; top: 80px; }

Industry use: data-table headers, section titles in long lists, sidebars and table-of-contents panels.
